# Social Media Platform Management System

A Java-based desktop application for managing a social media platform with user authentication, posts, comments, likes, friends management, and user profiles. The application uses Oracle Database for data persistence and Swing for the graphical user interface.

## Features

### User Management
- User registration (Sign Up)
- User authentication (Sign In)
- Update user information
- Delete user accounts

### Post Management
- Create new posts
- Update existing posts
- Delete posts
- View posts with content and timestamps

### Comment System
- Add comments to posts
- Update comments
- Delete comments
- Track comment dates

### Likes Functionality
- Add likes to posts
- Update likes
- Remove likes

### Friends Management
- Add friends
- Update friend relationships
- Delete friends
- Track friend request status

### Profile Management
- Create user profiles
- Update profile information (bio, profile picture)
- Delete profiles

## Technology Stack

- **Language**: Java (Core Java, JDBC)
- **Database**: Oracle Database (11g/12c/19c)
- **GUI Framework**: Java Swing
- **IDE**: Any Java IDE (Eclipse, IntelliJ IDEA, NetBeans)
